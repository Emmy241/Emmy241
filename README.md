## Featured Project

### [Security Engineering Portfolio — LendStack](https://github.com/Emmy241/security-portfolio)

A security engineering case study built around a fictional multi-tenant Banking-as-a-Service and lending platform.

The project explores how security requirements can be applied across the lifecycle of a financial SaaS platform, from architecture and application development to monitoring, incident response, and governance.

The work includes:

- **Security Architecture:** System design, attack surface analysis, trust boundaries, and STRIDE-based threat modelling.
- **Application Security:** API assessments, authentication and authorization testing, vulnerability analysis, proof of concepts, and remediation.
- **Cloud & Detection Engineering:** Security monitoring, detection logic, MITRE ATT&CK mapping, and incident response workflows.
- **Database Security:** PostgreSQL Row-Level Security, tenant isolation, privileged-role controls, and CI validation.
- **AI Security:** Threat modelling for agentic APIs, prompt injection, data exfiltration, and third-party LLM exposure.
- **Governance & Risk:** Risk registers, control observations, and security considerations mapped to relevant financial and security frameworks.
